One word for the boss who never sleeps — he only feeds, after dark, on everyone else's calendar.

`main.py` (Python 3) writes the entry to `/output/entry.txt`:

> calendar-vampire

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
